# keyword-judge · 关键词判定器

出海建站用的**关键词可行性判定器**。填进实测数据（KD、所需外链网站数、趋势形态等），按三档标准输出「通过 / 待定 / 淘汰」，并给出逐项理由与可直接粘进记录表的 Markdown 行。

单文件静态页，零构建、零后端、无第三方依赖（截图识别按需从 CDN 加载 Tesseract.js）。

- 线上地址：<https://keyword-judge.sevenqi0728.workers.dev>
- 本地打开：直接双击 `public/index.html`

---

## 一、它解决什么问题

选词决定上限。建站、优化、外链都只是在放大一个选择——**选择错了，后面每一步都是浪费**。

判断一个词值不值得做，需要看四五项独立指标，且每项都有门槛。人脑记不住这些门槛，容易凭感觉放行。这个工具把门槛固定下来，把判断过程显性化：哪一项过了、哪一项超了、超了几倍，全部写出来。

## 二、三档标准

| 档位 | KD | 所需外链站 | KGR | 趋势下降/尖刺 | 品牌词 | 风险门槛 |
| --- | --- | --- | --- | --- | --- | --- |
| **严格**（第一个练手站） | < 10 | < 10 | < 0.25 | **硬否决** | 一票否决 | ≥2 项 → 待定 |
| **中等**（第二、三个站） | < 29 | < 25 | < 0.5 | 仅警告 | 一票否决 | ≥3 项 → 待定 |
| **宽松**（追新词/热点） | < 49 | < 50 | < 1 | 仅警告 | 仅警告 | 不拦截 |

切换档位会同时重置门槛数字与三个开关。手动改动任意一项后，界面标记为「自定义」，避免出现「看着是严格档、参数其实被改过」的误读。

### 数值出处

| 规则 | 出处（教程章节） |
| --- | --- |
| `KD < 10`、`外链站 < 10` | 《第 2 步：找需求定关键词》「看竞争对手强弱：KD + 亲眼看搜索结果」；《第 1 步：定方向》新手村阶段表（数据引自《【哥飞解答】第一个出海站》） |
| `KGR < 0.25 / 0.25—1 / > 1` | 《第 2 步》「看网页供应量：intitle 与 KGR」（数据引自《奥赛的经验分享》，2024-11-26） |
| 趋势三形态（季节 / 短暂爆火 / 走下坡路） | 《第 2 步》「看趋势形态，排除假机会」 |
| `KD < 29`（保小图大） | 《第 2 步》「老词怎么挖长尾」 |
| Sitelinks 为负面信号、品牌词难以取得首位 | 《第 2 步》「直接去谷歌搜索，亲眼看前 10 名」 |
| 候选表列名 | 《第 2 步》开头「一张候选词表」 |

> 仓库：`qiayue/OpenGeFei` · 分支 `claude/ecstatic-gauss-12hlsv` · commit `4b9243a6737824957b937864c9446c0ce2c3be45`

**教程未作规定、由本项目设定的部分**：中等档的外链阈值 25 与 KGR 0.5、宽松档的 49 / 50 / 1.0、「趋势下降视为硬指标」、「风险计数」机制。教程对这类关键词的判断是「并非不可做，关键在于了解其热度特征」，因此趋势硬否决默认关闭，仅作提示。

## 三、使用

1. 在 Google Trends 找候选词，在谷歌、Ahrefs 取数
2. 把数据填进左侧（带 `*` 为必需）
3. 点「判定」或按 `⌘↵`
4. 右侧给出结论、三档对比、逐项明细；点「复制这一行」粘进记录表

**取值说明**（界面每个字段旁的「?」也有同样内容；界面上必填项在前，选填项在后）：

| 字段 | 必填 | 怎么取 |
| --- | --- | --- |
| 关键词 | ✅ | 从 Trends 或搜索结果里原样复制英文词，不翻译、不加引号 |
| Ahrefs KD | ✅ | `ahrefs.com/keyword-difficulty` 输入关键词，看圆环数字（0—100） |
| 所需外链网站数 | ✅ | 同上页面 `…need followed backlinks from ~N websites` 里的 N |
| 趋势形态 | ✅ | Trends 拉 12 个月与 5 年，判断季节 / 尖刺 / 下降 / 平稳 |
| 前 10 名构成 | ✅ | 谷歌搜这个词，看前 10 是专站首页还是大站内页 |
| intitle 结果数 | 选填 | 谷歌搜 `intitle:"关键词"`（带引号）→ 点「工具」→ 右下角「找到约 X 条结果」，仅用于算 KGR |
| 月搜索量 | 选填 | 没有 Ads 账号时用 Trends 参照词估算；留空则跳过 KGR |
| 附加标记 | 选填 | 品牌词 / 有 Sitelinks / .com 可注册，用于风险计数 |

### 快捷取数按钮

每个取数字段旁有跳转按钮，省去手动打开站点、输入关键词的步骤。**能力因站点而异**：

| 按钮 | 目标链接 | 是否自动填入关键词 |
| --- | --- | --- |
| 查 Ahrefs（KD / 外链数两处） | `https://ahrefs.com/keyword-difficulty` | ❌ 该站免费工具不读取 URL 参数，改为**自动复制关键词到剪贴板**，打开后按 `⌘V` 粘贴并回车 |
| 看 Trends | `https://trends.google.com/trends/explore?date=today%2012-m&hl=en&q=<关键词>` | ✅ 直接带词，默认展示近 12 个月 |
| 看搜索结果 | `https://www.google.com/search?hl=en&num=20&q=<关键词>` | ✅ 直接带词 |
| 搜 intitle | `https://www.google.com/search?hl=en&num=20&q=intitle%3A%22<关键词>%22` | ✅ 引号由程序添加，整体编码 |

**关键词处理规则**（`normalizeKw`）：

1. 全角空格 `U+3000` → 半角空格；移除零宽字符（`U+200B`—`U+200D`、`U+FEFF`）
2. 连续空白（含制表符、换行）折叠为单个空格
3. 去除首尾的直引号与中文引号（`"` `'` `“”` `‘’`）
4. 超过 200 字符截断
5. 拼接 intitle 查询时，额外剔除关键词内部的 `"`，避免破坏引号短语结构
6. 最终由 `encodeURIComponent` 整体编码（空格→`%20`，`&`→`%26`，`#`→`%23`，`:`→`%3A`，`"`→`%22`）

**异常处理**：

| 情况 | 表现 |
| --- | --- |
| 关键词为空 / 纯空格 | 按钮置灰不可点，悬停提示「请先在上方填写关键词」；即使被程序调用也只弹提示、不跳转 |
| 链接拼接异常（未知工具标识） | 捕获异常，提示「链接生成失败，请手动访问对应站点」，不跳转 |
| 剪贴板不可用（非安全上下文、权限被拒） | 降级到 `execCommand('copy')`；仍失败则提示「请手动输入该关键词」，跳转照常发生 |
| 浏览器拦截新窗口 | 新窗口通过程序化点击 `<a target="_blank" rel="noopener noreferrer">` 打开，属用户手势触发，一般不会被拦截 |

### 新词模式（KD 无数据时使用）

**问题**：Ahrefs 对新词或极低搜索量词会返回 `No data for "关键词"`。这不是难度为 0，而是**数据不足**。此时 KD 与外链数拿不到，常规流程会卡住。硬把 KD 填 0 会被判为"通过"，属于错误结论。

**开启方式**：两处开关互为镜像，任选其一，状态实时同步：

1. **KD 字段下方的常显开关**（推荐）：「新词模式（KD 无数据）」— 开启后自动把光标移到 `intitle 结果数`
2. 「门槛与附加规则」卡片中的同名开关

关闭后 KD 与外链数的原值会自动恢复，可反复开关。

**生效后发生什么**

| 项目 | 常规模式 | 新词模式 |
| --- | --- | --- |
| Ahrefs KD | 必填，硬指标（`< 10/29/49`） | 置灰为 `N/A`，**不参与判定** |
| 所需外链网站数 | 必填，硬指标（`< 10/25/50`） | 置灰为 `N/A`，**不参与判定** |
| intitle 结果数 | 选填，仅用于算 KGR | **转为必填**，作为 `allintitle` 供给量进入硬指标 |
| 前 10 构成 | 软指标（计入风险） | **转为硬指标**：`专站首页为主` 直接淘汰 |
| 趋势形态 | 硬/软由开关决定 | 不变 |
| KGR | 计算并展示 | 不计算（无搜索量基准） |
| 结论文字 | — | 末尾追加「（新词模式：未使用 KD 与外链数据，属定性判断）」 |
| 记录行 | `KD=54`、`外链=99` | `N/A（新词）`、`N/A`，规则签名带 `新词模式 allintitle≤50` |

**allintitle 阈值**（按档位自动带出，可手动改）

| 档位 | 阈值 | 含义 |
| --- | --- | --- |
| 严格 | ≤ 50 | 供给量低于 50 个标题命中页面 |
| 中等 | ≤ 200 | |
| 宽松 | ≤ 500 | |

其中 **≤ 5 条** 会在结论里特别标注「无人防守」（业界常用的"无护城河 SERP"判据）。

**取值方式**：Google 搜 `allintitle:"preset editor capcut"`（注意是 `allintitle` 而非 `intitle`），点「工具」读取结果数，填进 `intitle 结果数` 字段。

**边界与异常**

| 情况 | 行为 |
| --- | --- |
| 开启新词模式但未填 intitle | 校验拦截，提示「新词模式必填：填 allintitle 结果数」 |
| 开启前已填 KD/外链 | 值暂存并在输入框清空、置灰；**关闭开关后自动恢复**，不会丢失 |
| intitle 为 0 | 视为供给完全空白，作为提示展示，不判为错误 |
| 切回常规模式但 KD 为空 | 恢复常规校验，提示「必填；Ahrefs 无数据请勾选「新词模式」」 |

**限制**：新词模式是**定性判断**，不是量化评分。它不能回答"难度是几分"，只能回答"供给是否空白、前 10 有没有人占位"。因此配套要求是早做、快速上线，用先发优势弥补无法量化的风险。

### 数据导入入口的位置

所有导入/识别按钮都放在**它所服务的字段旁边**，不再集中放在页面顶部：

| 维度 | 字段 | 按钮 | 行为 |
| --- | --- | --- | --- |
| 竞争度 | Ahrefs KD | 查 Ahrefs、**截图取数** | 「截图取数」只填 KD 与外链数（同属 Ahrefs 一页） |
| 竞争度 | 所需外链网站数 | 查 Ahrefs | — |
| 需求趋势 | 趋势形态 | **走势图**、**CSV** | 走势图展开面板后可拖入/粘贴截图；CSV 直接弹出文件选择 |
| 搜索结果 | 前 10 名构成 | 看搜索结果 | 打开 Google 搜索 |
| 供给量 | intitle 结果数 | 搜 intitle、**截图取数** | 「截图取数」只填 intitle |
| 供给量 | 月搜索量 | — | 手动填 |

**交互约定**

- 截图取数：点击后在**当前字段下方**显示一行状态（如「已识别 2 项：KD 54、外链站 99」），填入的值标黄底，手动改动后自动去色。
- 走势图：点击后在「趋势形态」下方**原地展开**识别面板（含时间范围选择 + 拖拽区），不跳页、不弹窗；右上角 `×` 收起。
- CSV：点击直接打开文件选择，识别完成后结果同样展现在该面板内，并显示「数据来源：CSV · 53 个数据点 · 跨度 12.0 个月」。
- 全部识别结果都带「填入趋势形态」按钮，一键写回下拉框。

### CSV 导入（最准确的方式）

Google Trends 页面右上角的下载按钮 → 导出 `multiTimeline.csv` → 在「趋势形态」旁点 **CSV** 导入。

**解析规则**

1. 去掉 BOM、兼容 `\r\n`
2. 只接受首列为 `YYYY-MM-DD` 的行（表头、类别说明、空行自动跳过）
3. 数值为空的行跳过；Google 的 `<1` 按 0.5 处理
4. 时间跨度由首末日期相除 30.44 天/月得出（周数据即真实周跨度）
5. 归一化与图像路径**完全一致**：`(v - min) / (max - min)`

**与图像识别的关系**

- 两条路径共用同一套特征计算与分类函数（`trendFeatures` + `classifyTrend`），因此**同一份数据的判定结果必然一致**
- 差异只在数据精度：CSV 用真实数值，图像靠像素反推
- 已用 `stress checker` 的导出文件核对：页面显示斜率 `0.078`、R² `0.007`、峰宽 `9.4%`、峰值/基线 `3.48`、波动系数 `0.75`，与独立脚本计算结果一致；判定同为「驼峰」

### 趋势图识别（走势图 → 形态）

在「趋势图识别」卡片上传 Google Trends 截图（或同格式折线图），自动提取曲线并判定形态。**全程在浏览器本地完成，图片不上传。**

**输入要求**

| 项 | 要求 | 原因 |
| --- | --- | --- |
| 来源 | Google Trends 截图最佳 | 依赖线条色值 `rgb(66,133,244)`；其他配色需先做颜色标定 |
| 宽度 | ≥ 800px | 低于此值曲线会糊成一片，识别可靠性下降（会有提示） |
| 内容 | 完整曲线 + 时间轴 | 时间轴跨度用于计算 12 个月滞后周期 |
| 时间范围 | 上传前在面板中选择（7 天 / 90 天 / 12 个月 / 5 年） | 选错会导致「季节性」判断失效，其他形态不受影响 |
| 避免 | 深色模式、滤镜、截图选中高亮 | 会破坏颜色识别 |

**输出**

- **主形态**（9 类之一）+ **置信度**（0—100%，低于 60% 用黄色进度条提示）
- **修饰标签**：末段拉升 / 末段回落 / 峰值突出 / 无长期趋势 / 波动较大 / N 个峰
- **主判据**：一句话说明为什么判成这类（含具体数字）
- **次选形态**：第二可能的类别及其依据——这是避免"单一结论误导"的关键
- **数据质量**：曲线覆盖率、图宽
- **无法明确归类时**：给出「最佳与次选分差不足」的具体原因，并建议换周期重试
- 一键「填入趋势形态」写回判定表单

**分类依据（初版阈值）**

| 形态 | 判据 |
| --- | --- |
| 尖刺 | 峰值宽度 < 5% 且 峰值/基线 > 3（宽松档：< 9% 且 > 2.5） |
| 驼峰 | 峰位在 30%—70%、\|斜率\| < 0.28、尾段/中段 < 0.68 |
| 箱体震荡 | \|斜率\| < 0.2、波动系数 < 0.45、峰宽 > 15% |
| 上升 | 斜率 > 0.45 且 R² > 0.55（弱档：斜率 > 0.25 且 尾段/中段 > 1.6） |
| 下降 | 斜率 < -0.45 且 R² > 0.5（弱档：斜率 < -0.25 且 尾段/中段 < 0.6） |
| 阶梯上升 | 斜率 > 0.28、R² < 0.5、尾段/中段 > 1.5 |
| 多峰 | 显著峰 ≥ 2 个（阈值 均值+0.5σ，间隔 > 全宽 8%） |
| 季节 | 12 个月滞后自相关 > 0.35（需时间范围 ≥ 24 个月） |
| 平稳 | \|斜率\| < 0.15 且 波动系数 < 0.3 |

**已知限制**

- 归一化使用曲线自身最高/最低点，**不是 0—100 绝对热度**（尚未读 y 轴刻度）。
- 形态命名本身存在主观性：同一张图"横盘后拉升"与"尖刺"都能自圆其说，因此工具给**多标签 + 依据**而非单一裁定。
- 曲线提取依赖颜色识别，非 Google 配色的图需要调整色值阈值。

### 其它功能

- **截图识别**：点击 / 拖入 / `⌘V` 粘贴截图，尝试自动填 KD、外链数、intitle 数、趋势方向。识别值标黄底，需人工核对。引擎为 Tesseract.js（首次需联网加载数 MB），失败时明确提示手动填写。
- **本次记录**：主动判定过的词进入右侧列表，点击可回填当时的数据与规则；「导出记录」下载 Markdown。
- **草稿自动保存**：输入内容存在 `localStorage`，重开页面自动恢复。

## 六、已知限制

- **判定逻辑不联网**，数据全靠人工输入。不要期待它替你去查——谷歌搜索、Ahrefs、Trends 都有反爬或无公开 API（详见项目讨论：全自动取数的真实成本是每月几十美元的 API 费用）。
- **OCR 准确率有限**。多栏紧凑截图、缩放过的图片、非英文界面容易出错，因此识别结果一律标黄待核对。追求高准确率请把截图直接交给具备视觉能力的模型。
- **门槛是社群经验值，不是实验结论**。`10` 这个数字的含义是「新手基准」，不是物理常数，可随时按自己的外链能力调整。
